🏦 Java Bank Account

A simple banking system built with Java to demonstrate fundamental Object-Oriented Programming (OOP) concepts.

The program allows users to create a bank account, view account information, deposit money, and withdraw money through a simple console-based interface.

✨ Features

- Create a bank account
- Display account information
- Deposit money
- Withdraw money
- Check current balance
- Validate deposit and withdrawal amounts
- Simple interactive menu

🧠 OOP Concepts

This project demonstrates:

- Class — defines the structure of the bank account
- Object — creates a real account from the class
- Constructor — initializes the account
- Methods — perform account operations
- Encapsulation — protects account data using private variables

🛠️ Technologies

- Java
- Object-Oriented Programming (OOP)
- Scanner
- Conditional statements
- Switch statement
- Do-while loop

▶️ How to Run

Make sure Java is installed on your computer.

Compile the program:

javac BankAccount.java

Run the program:

java BankAccount

💰 Available Operations

1. Account Information
2. Deposit Money
3. Withdraw Money
4. Exit
